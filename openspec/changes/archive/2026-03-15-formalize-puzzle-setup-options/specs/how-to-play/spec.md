## ADDED Requirements

### Requirement: How to Play page explains inline setup interactions
The system SHALL explain that some puzzles offer optional setup interactions on the game screen before the first move.

The page SHALL describe that setup-capable puzzles may allow the player to shuffle pieces or remove highlighted listed blocks before starting to move pieces.

#### Scenario: Setup step described
- **WHEN** the user reads the How to Play page
- **THEN** the page SHALL state that some puzzles include optional setup actions on the game screen before gameplay begins

#### Scenario: Shuffle and removable-block choices described
- **WHEN** the user reads the setup section
- **THEN** the page SHALL explain inline shuffle and removable-block choices when those options are present
